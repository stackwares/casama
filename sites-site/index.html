An address like bakery.{{ZONE}} is a site someone built with their Casama bot and put on the web. Casama hosts it; the person who published it wrote it.

What these addresses are

  • Each address is one site, published by one Casama workspace.
  • Casama doesn't write, check or endorse the sites. A site never asks for a Casama password.
  • Sites can only send what you type in their forms to Casama, never to another server.
  • A site on its own domain shows the same small Report link at /_casama/report.
