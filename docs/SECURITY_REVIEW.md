# Security review (Phase 8)

Review of Casama against the threat table in SPEC "Security and privacy", 2026-11-10. Each control
lists its evidence (automated tests that run in this repository) and what is left. An outside
penetration test is still recommended before a public hosted launch (docs/NEEDS-FROM-OLIVER.md).

## Fixes made during the review

- **Computers had no memory limit by default.** The supervisor passed `COMPUTER_MEMORY_MB` through as
  `undefined` when unset, and the spread overwrote the 1 GB default, so containers ran without a
  memory cap unless that variable was set. Fixed in `packages/sandbox/src/docker/provider.ts`;
  caught by the new pentest suite.
- **Audit log gaps.** Owner quota changes, secret deletion and Cloud Connect key creation and
  revocation now write to `audit_log` (credential changes, approvals, lease changes, computer
  deletion, checkpoints and settings already did).
