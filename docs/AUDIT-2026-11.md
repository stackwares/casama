# Audit, November 2026

A full re-audit of the repository after Waves 2 to 4, done overnight on 2026-11-11 while Oliver slept. Scope:

- server, agent, contracts, database and migrations
- sandbox and supervisor
- Flutter client, Dart SDK and CLI
- infra and docs

Method:

- Four read-only reviewers worked in parallel: security, roadmap acceptance and bugs, consistency, and quality and UX.
- A from-scratch self-host install ran inside an isolated Docker-in-Docker container (no cached images, volumes or `.env`).
- The Phase 8 gate was re-run locally.
- Every finding below was checked against the code before fixing.

The decisions this audit made are recorded as D-154 in `docs/DECISIONS.md`.

## Summary

- **Fresh self-host installs were broken in four separate ways.** Auth didn't start, the API and worker crashed, chat messages failed with a database permission error, and runs couldn't read secrets. The installer's readiness check passed anyway. All are fixed and verified end to end on a clean install:
  - sign-up
  - workspace and bot creation
  - a chat message starting a run that the worker picks up
  - upgrade by re-running the installer
- **Personal data could reach teammates.** A linked bot's request ran with the owner's personal access, and device and health data could end up in chats, run events and memory that every user of a team bot can read. Fixed with private conversations and an acting-person rule.
- **Worker robustness:** one failing step or routine could stall the minute tick or lose runs. Fixed with per-step and per-routine isolation, a queued-run sweeper, and locks.
- **Performance:** several minute-tick queries scanned large tables. Fixed with indexes, an hourly cadence and caching.
- **Consistency:** SPEC, DECISIONS, NEEDS, the launch checklist, Compose and the docs site had drifted. All updated.
- **Client:** analyzer warnings, error states that spun forever, phone overflow and hardcoded strings. All fixed.

## Performance

All in fd3c75d:

- **Encryption sweep:** it scanned 12 tables per sealed workspace every minute. Sealed workspaces are now re-checked every 15 minutes, and `(org_id, created_at)` indexes were added.
- **Device data retention:** it scanned the whole table every minute. It now runs hourly over an indexed slice. Indexes were added on `device_event_log` and `device_requests`.
- **Leave-now:** it called the maps API up to 180 times per event. It now caches travel times for 10 minutes and looks only 2 hours ahead.
- **Unread badge:** got a partial index. Read notifications are deleted after 180 days.
- **Routine trigger types:** got an expression index.
