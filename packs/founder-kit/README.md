# Founder kit

A Casama pack: a **Chief of staff** bot with an investor-update skill, a morning plan on weekdays
and a review on Fridays. It also adds the gallery's decision memo, spec, competitive brief and
weekly report skills, and asks you to connect Notion and Google Calendar.

Other Agent Plugins clients see a plugin with the `investor-update` skill.

Check it: `npx @casama/plugin-check packs/founder-kit --strict`
