# PaaS fit and monthly floor for the Casama compose stack

Research date: 11 November 2026. Amounts are the figures on the cited pages that day. USD and EUR are not converted. Model API fees are excluded. The stack is `infra/compose/docker-compose.yml`: Supabase Postgres 17 plus GoTrue, PostgREST, Realtime, and Kong; a Node API; a Node worker; a supervisor that bind-mounts `/var/run/docker.sock` and starts sibling computer containers; an egress proxy; coturn; Caddy on ports 80, 443, and 8790. SearXNG is an optional profile. The default file keeps `db`, `auth`, `rest`, `realtime`, `kong`, `api`, `worker`, `supervisor`, `egress`, `turn`, and `caddy` running. The price question below is the smaller set the assignment asked for: API, Postgres, and worker, always on.

## Current prices for the smallest always-on setup that includes a database

On 11 November 2026 the published floors that include a database are about $15.58 per 30 days on Fly.io for three always-on Machines plus a 10 GB volume in Ashburn, or $38 before any app Machines if the database is Managed Postgres Basic; $5 on Railway as the Hobby subscription, which pays for half a gigabyte-month of RAM and nothing else; about $20.30 on Render for one paid web service, one paid worker, and the smallest paid Postgres with 1 GB of disk; and €5.99 per month excluding VAT for a Hetzner CX23 that the cost-optimized page listed as not available.

## Explicit blocks: privileged Docker, UDP for TURN, free-tier sleep, egress

### Takeaway

The compose file’s supervisor needs the host Docker socket. Fly’s own Machine doc describes a VM started from an image and does not document a host socket. Railway’s fetched docs describe HTTP public networking and do not document a socket. Render’s fetched docs describe public web services as HTTP and private services as any protocol only inside Render. Fly does publish UDP, on a dedicated IPv4, and requires a bind address that coturn’s `0.0.0.0` listener does not use. Free or trial modes on Fly, Railway, and Render do not keep this stack up for a month. A Hetzner VPS is a customer VM on which Docker can be installed; the cost-optimized page does not say UDP is disabled.

### Cited Findings

- The supervisor service bind-mounts `/var/run/docker.sock`. The compose comment calls it the only service with Docker access. It is configured to start `computer-headless` and `computer-desktop`. Default `COMPUTER_MEMORY_MB` is 2048. `WARM_POOL_SIZE` defaults to 0. — [infra/compose/docker-compose.yml](file:///Users/nemoryoliver/Desktop/Projects/Kasama/infra/compose/docker-compose.yml)
- Coturn is started with `--listening-ip=0.0.0.0`, `--listening-port` default 3478, and relay ports defaulting to 49160–49260. The compose file publishes `3478/tcp` and `3478/udp` only. — [infra/turn/start-turn.sh](file:///Users/nemoryoliver/Desktop/Projects/Kasama/infra/turn/start-turn.sh); [infra/compose/docker-compose.yml](file:///Users/nemoryoliver/Desktop/Projects/Kasama/infra/compose/docker-compose.yml)
- Casama’s self-hosting page says 4 vCPU and 8 GB RAM for a few computers at once, about 2 GB RAM per running computer, and 40 GB of disk or more. The installer warns below about 8 GB. — [docs-site/self-hosting/index.md](file:///Users/nemoryoliver/Desktop/Projects/Kasama/docs-site/self-hosting/index.md)
- A Fly Machine is “the configuration and state for a single VM.” `fly machine run` starts that VM from an image. The overview lists ephemeral storage, an optional volume, and region placement. It does not mention a host Docker socket, privileged mode, or a Docker daemon. — [Fly Machines overview](https://fly.io/docs/machines/overview), fetched 11 November 2026
- Fly’s UDP doc, as returned in search on 11 November 2026: public UDP requires a dedicated IPv4; shared IPv4 and public IPv6 are not usable for UDP. The process must bind `fly-global-services` on the same port that is used externally. The doc says `0.0.0.0` is the wrong source address for UDP replies. TCP must not bind `fly-global-services`. There is no per-flow UDP load balancing. QUIC is not supported. UDP over the private IPv6 network does work. — [Running apps on UDP and TCP](https://docs.fly.io/networking/udp-and-tcp), search extract 11 November 2026
- Fly public egress is $0.02 per GB in North America and Europe, $0.04 in Asia Pacific, Oceania, and South America, and $0.12 in Africa and India. Inbound transfer is free. Same-region private transfer is free for organizations on granular rates. Cross-region private transfer is $0.006 per GB in North America and Europe. — [Fly.io resource pricing](https://docs.fly.io/about/pricing), fetched 11 November 2026
- Railway public networking, fetched 11 November 2026, is described as HTTP/HTTPS, with Railway domains, custom domains, and automatic SSL. The page does not mention UDP, a Docker socket, or privileged mode. — [Railway public networking](https://docs.railway.com/reference/public-networking), fetched 11 November 2026
- Railway Serverless, on the comparison page last updated 30 October 2026, is a feature “when enabled.” A service with no outbound requests for over 10 minutes is put to sleep and incurs no compute charges while asleep. It wakes on the next incoming request. — [Railway vs Render](https://docs.railway.com/platform/compare-to-render), fetched 11 November 2026
- Railway also bills a separate VM primitive, used for its own sandboxes and cloud agents, at $50 per GB-month of RAM and $50 per vCPU-month, plus egress at $0.05 per GB. Memory stays billable while that VM waits. That section does not say customers receive a Docker socket. — [Railway pricing plans](https://docs.railway.com/pricing/plans), fetched 11 November 2026
- Render free web services spin down after 15 minutes without inbound HTTP or WebSocket traffic and take about a minute to start again. They cannot attach a persistent disk and cannot receive private-network traffic. Free instance hours are 750 per workspace per calendar month; at zero, free web services are suspended until next month. Free Postgres expires 30 days after creation, then has 14 days to upgrade before deletion, is capped at 1 GB, and one free database is allowed per workspace. The doc says upgrading the service to any paid compute plan removes the free-instance limitations, and that upgrading the workspace plan does not. Outbound ports 25, 465, and 587 are blocked on free web services; port 25 is blocked for all services. — [Deploy for free](https://render.com/docs/free), fetched 11 November 2026
- Render private services “can listen on almost any port and communicate using any protocol” and are not reachable from the public internet. - Render Hobby outbound bandwidth is 5 GB, then $0.15 per GB on the public internet. — [Render outbound bandwidth](https://render.com/docs/outbound-bandwidth), fetched 11 November 2026
- Coolify’s compose doc says a normal deployment creates a resource-specific network, adds management labels, and routes public HTTP and HTTPS through its proxy to an internal container port. It says not to publish `ports:` unless the service must be reachable directly on a server interface, because a published host port bypasses the proxy. Raw mode “applies the definition without most Coolify modifications.” The page does not mention `/var/run/docker.sock` or privileged mode. — [Coolify Docker Compose](https://coolify.io/docs/applications/builds/docker-compose), fetched 11 November 2026

- Hetzner’s cost-optimized page includes stateful firewalls at no extra charge, assigned by the customer, and 20 TB of traffic on the EU plans it lists. It does not say UDP is disabled. — [Hetzner cost-optimized cloud](https://www.hetzner.com/cloud/cost-optimized/), fetched 11 November 2026

### Inferences

- The fetched platform docs do not show a way to mount the host Docker socket on Fly, Railway, or Render. On Fly the unit of compute is one VM per Machine. On Railway and Render the fetched networking docs describe their own edge, not a Docker daemon shared with sibling containers. Splitting the file into one service per process can cover an API, a worker, and a database. It does not cover the supervisor starting `computer-headless` or `computer-desktop` on the same daemon.
- Coturn’s `--listening-ip=0.0.0.0` is the address Fly’s UDP doc says not to use. A dedicated IPv4 at $2 per month is required before public UDP on Fly. The relay range 49160–49260 is not in the compose `ports:` list, so a default `docker compose up` does not publish those UDP ports on a VPS either.
- Railway’s fetched public-networking page documents HTTP and HTTPS. Render’s fetched private-service page says arbitrary protocols only for services that are not on the public internet, and its web services are the public HTTP kind. This pass did not fetch a 2026 sentence that says the words “inbound UDP is disabled” for either product. The docs that were fetched also do not describe a public UDP listener.
- Sleep is a free-tier or opt-in behavior, not the paid always-on price. Fly has no ongoing free allowance, and a bill under $5 is waived only for a personal org. Railway Serverless sleeps a service after more than 10 minutes without outbound requests, and the comparison page presents that as enabled on purpose. Render free web services sleep after 15 minutes without inbound HTTP or WebSocket traffic. Render free Postgres ends after 30 days. A paid Render compute plan is how the free-tier doc says those limits come off. A Railway service with Serverless left off stays in the usage meter the whole time it runs.
- Lowest cited public egress rates: Fly $0.02 per GB in North America and Europe; Railway $0.05 per GB with no included gigabytes on the plans page; Render $0.15 per GB after 5 GB on Hobby; Hetzner 20 TB included on the EU cost-optimized plans, with the overage rate not readable in the page extract.
- On a VPS, Docker is software the customer installs. The socket mount is then a host feature. Coolify raw mode is the documented path that applies a compose file with fewer rewrites. The normal Coolify path rewrites networking and tells the user not to publish host ports. Dokploy’s install extract requires 80, 443, and 3000 to be free, and Caddy in this compose file publishes 80 and 443, so those two cannot bind the same ports at once without changing one of them.

### Gaps

- No 2026 Fly doc fetched here says a Docker daemon inside a Machine is supported, and none was fetched that forbids it. The Machine overview only describes one VM per Machine.
- No Railway or Render docs page fetched here uses the words “privileged” or `docker.sock`. Search snippets pointed at forum threads; those threads were not fetched, so their quotes are not repeated here.
- No Railway or Render docs page fetched here states a current inbound-UDP policy in those words. Absence of UDP from the HTTP docs is not the same as a fetched prohibition.
- Coolify’s compose doc does not say whether a `/var/run/docker.sock` bind is kept, stripped, or blocked. Raw mode is the closest statement, and it does not name that path.
- No fetched Hetzner page states the default firewall policy. UDP is not shown as blocked, and it is not shown as open by a quoted default rule.
- The Fly UDP page was a search extract, not a full-page fetch. The bind-address and dedicated-IPv4 rules in that extract are specific enough to cite, and the page was not re-read as a full document.
- Whether Fly will accept on the order of 100 discrete UDP services for coturn’s relay range was not in the UDP extract.

## Whether a self-hosted panel on a cheap VPS is cheaper than the PaaS and still runs this compose file

### Takeaway

Self-hosted Coolify and Dokploy run on a Linux server the customer pays for. On the Hetzner page fetched 11 November 2026, that server’s displayed x86 entry price is €5.99 per month excluding VAT for a CX23 with 4 GB RAM, and that SKU was marked not available. That cash figure is lower than the Fly three-Machine estimate of $15.58 per 30 days, the Render three-service estimate of about $20.30, and Fly Managed Postgres Basic at $38, before VAT and before any euro conversion. It is also the arrangement whose host can run Docker. Railway’s $5 Hobby subscription can be a lower invoice only while usage stays inside $5, and the fetched Railway docs do not provide the Docker socket or a public UDP listener. CX23’s 4 GB is below Casama’s own 8 GB guidance once a computer is running.

### Cited Findings

- Coolify self-hosted install: a Linux server with SSH, minimum 2 CPU cores, 2 GB RAM, and 10 GB free disk, amd64 or arm64. The doc says smaller servers are possible and not recommended. The installer is a shell script run on that server. The dashboard listens on port 8000. The page suggests Hetzner as a provider and does not print a software price. — [Start with self-hosted](https://coolify.io/docs/start-with-self-hosted), fetched 11 November 2026
- Coolify deploys Docker Compose from Git or from a pasted definition. Normal mode adds a network, labels, and proxy routing. Raw mode applies the file with fewer modifications. ### Inferences

- The monthly floor of a self-hosted panel is the VPS, because neither install doc fetched here charges for the panel. Against the PaaS rate cards, one Hetzner CX23 at €5.99 excluding VAT is less cash than the Fly three-Machine estimate ($15.58 per 30 days), the Render three-service estimate (about $20.30 with 1 GB of database disk), and Fly Managed Postgres Basic ($38), before VAT and before conversion. - A VPS is the place this compose file can run as Docker Compose, because the customer controls the daemon the supervisor mounts. Coolify raw mode is the documented way to apply that file with fewer proxy rewrites. Dokploy’s install extract requires ports 80 and 443 free for its own proxy, and Caddy publishes those ports, so one of the two publishers has to move.
- CX23’s 4 GB meets Coolify’s 2 GB minimum and Dokploy’s 2 GB minimum. It does not also hold a 2048 MB computer plus Postgres plus the panel inside Casama’s 8 GB guidance. That is arithmetic from the project’s own defaults, not a load test. The 10 November third-party CX33 listing (8 GB, €8.49 excluding VAT and excluding IPv4) is the next x86 step that table shows. The official page did not name that SKU, and CX23 was marked unavailable, so €5.99 was not an orderable price at fetch time.
- CAX11 is an ARM price on the 10 November table. Coolify documents arm64. This pass did not check whether the Supabase Postgres image or the Casama images publish arm64 builds.
- Disk: Dokploy’s extract asks for 30 GB, and CX23 has 40 GB. Casama’s self-hosting page says the images take about 6 GB and asks for 40 GB or more. CX33’s 80 GB on the 10 November table is the listing with more image room. Those disk figures are the published sizes, not a measured image pull of this repository on that day.
