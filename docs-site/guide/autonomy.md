# Autonomy and approvals

| Level                    | The bot asks before                                                     |
| ------------------------ | ----------------------------------------------------------------------- |
| Ask always               | Any action with side effects                                            |
| Ask when risky (default) | High-risk actions, and medium-risk ones after reading untrusted content |
| Autonomous               | Nothing, except high-risk actions on personal computers                 |

Approvals appear in the app's inbox (with push notifications) and in `kasama runs`. Approve once or
"always allow this tool for this bot". Unanswered approvals expire.
