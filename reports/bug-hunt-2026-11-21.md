# Bug hunt report (2026-11-21)

Plan: `docs/BUG-HUNT-PLAN.md` (fix log in §9). Three tracks ran in parallel against the local stack:
web + macOS + websites, iOS + iPad + Android + Fold + Wear OS, and server + database + suites.

## Result

- **24 bugs fixed**, each committed on its own and pushed to `origin/main`; the full log with commits
  is in the plan §9. Nothing was deployed to production.
- **Suites on main at `5365c8249`:** `pnpm test` all pass (server 1509, agent 687, …), `pnpm typecheck`
  15/15, `pnpm lint` 0 errors (was 8), pgTAP 75 files / 721 checks pass (baseline; no migrations added).
- **Schema drift:** local DB was missing `public.user_last_active` (re-created; it broke every routine
  claim). After that, no drift locally or in production (read-only check).
- **Websites:** 1,090 local links crawled across casama.ai, gallery, docs and casama.link; no real 404s.

## Needs a deploy (Oliver's yes)

- **`public.casama_migrations` is open in production:** no RLS, and anon/authenticated have full rights,
  so anyone with the public anon key could edit migration records through `/rest/v1`. Fixed in the
  migrate scripts (`e2017e573`); production stays open until the next server deploy runs migrate, or
  until `alter table public.casama_migrations enable row level security` is run there.
- All server fixes above (API crash on `/telephony/stream`, stream crash, Stop not stopping tool calls,
  billing fixes, email masking, 500→400) only reach users after a server deploy.

## Needs Oliver (found, not fixed)

Security and auth
1. Waitlist bypass: a Pro/Max owner can invite, let the person sign up, revoke the invite and repeat.
2. For up to an hour after Sign Out Everywhere, the old token can still mint sign-in codes, watch keys
   and widget keys. Fix: check `auth.sessions` for the token's session in those three routes.
3. Sign Out Everywhere removes only this device's push/VoIP tokens; a lost phone keeps getting pushes
   and call rings.
4. Voice transcripts: the app supplies `assistant` turns, so a member can post replies the bot never wrote.
5. Smaller: FCM token takeover through the device-token handover trigger; reporting a teammate's
   private message; no body limit on `/hooks/*`.

Billing
6. RevenueCat refund of an older renewal takes back this period's credits; `REFUND_REVERSED` doesn't
   give them back (medium confidence).
7. Sandbox (TestFlight) credit packs grant real credits that never expire.
8. A partial Dodo refund of a credit pack takes back the whole pack.
9. Yearly upgrade top-up counts the year left, not the grant month.
10. Undoing a saved reset gives back neither the campaign budget nor the period allowance.
11. Billing row says "Upgrade to Pro" but the paywall opens on Plus.
12. Usage showed 1% used while the banner said credits were running low (not confirmed).

Chat and runs
13. Stop on a queued run does nothing until a slot frees (`RunSlots.acquire` can't be cancelled).
14. A message during a D-402 pickup run starts a second run instead of joining it.
15. Editing a message doesn't take the chat lock; a failed `startRun` returns 202 with no `run.failed`.
16. Attachments need computer hours: with none left the upload fails, the message goes without the
    file, and the bot claims it can read attachments without the computer.
17. Each failed call attempt (e.g. mic denied) creates a new empty "Voice call" topic.
18. A ticket's conversation shows the raw internal prompt as the person's own message.
19. Old runs from 2026-11-16 are still `running` locally (15 routine, 8 chat): no cleanup of stale runs.

App
20. Bot profile edits are thrown away on Back with no "discard changes?" prompt.
21. The iOS share extension shares only the file name, not the file.
22. Offline token refreshes throw unhandled `AuthRetryableFetchException`, which reaches the crash
    reporters as noise from every offline user.
23. A fake `expiresAt` (now + 1 day) and no retry on 401 give load errors after more than an hour in
    the background.
24. Wear wording: a typed reply is confirmed as "HEARD".
25. Android debug app used ~2.4 GB after many hot reloads and was killed; worth a release-build check.

Dev setup
26. `api-dev.casama.ai` returned 502 in 2 of 5 tries; two `cloudflared` processes are running.
27. The macOS debug app keeps a saved "Setup Test" session pointing at `localhost:8080`, which blocked
    the macOS core-path test.
