# Contabo leads five cheaper Casama hosts

The cheapest orderable fit for the Casama stack on 11 November 2026 is a **Contabo Cloud VPS 4 at €4.40 per month excluding VAT** for the first 24 months: **4 vCPU, 8 GB of RAM, and 100 GB of disk**, with root on the machine so Docker can run on the host and the supervisor can start bot computers beside Postgres and the API. Cheapest first, the rest of the five are **OVHcloud VPS-2 2027 at €7.21 per month excluding VAT on a 12-month term, or €8.49 with no commitment**, **RackNerd’s 8 GB special at $119.99 per year**, **Hostinger KVM 4 at €10.99 per month on a 24-month promotion**, and **Netcup VPS 1000 G12.5 at €14.50 per month including 19% VAT** on a 12-month term. All five sit well under the live Hetzner **CPX42 at €59.49 in Helsinki and €69.99 in Nuremberg** (8 vCPU, 16 GB, primary IPv4 included, VAT excluded), which is the next size once a 4 vCPU / 8 GB host is full. Fly.io, Railway, and Render stay off the five because the supervisor needs the host Docker socket and the docs fetched for those platforms do not provide one. The marketing site is already on Cloudflare’s free plan, and model API fees are a separate bill. The sources quote euros and dollars as published, with no conversion rate attached.

## Contabo’s €4.40 VPS is the cheapest Docker host

Casama’s own self-hosting page sizes one machine at **4 vCPU and 8 GB** for a few computers at once, about **2 GB of RAM per running computer**, and **40 GB of disk or more**, and the installer warns below about 8 GB ([self-hosting guide](file:///Users/nemoryoliver/Desktop/Projects/Kasama/docs-site/self-hosting/index.md)). The compose file’s default computer is **2048 MB**, the warm pool defaults to zero, and the supervisor is the only service that bind-mounts `/var/run/docker.sock` so it can start `computer-headless` and `computer-desktop` ([docker-compose.yml](file:///Users/nemoryoliver/Desktop/Projects/Kasama/infra/compose/docker-compose.yml)). Two computers at that default are 4 GB before the API, the worker, Postgres, Caddy, coturn, and the Supabase gateway containers. The project’s cost note sketches the same computers smaller, about **1 vCPU and 1 GB** each, which leaves more of the 8 GB for that platform ([COSTS.md](https://github.com/nemoryoliver/Kasama/blob/main/docs/COSTS.md)). No RSS profile of this repository was measured on the research day, so the fit is that written guidance. pgvector rides inside the Postgres image the compose file already starts, on whichever of these hosts runs that image.

Contabo is the vendor that sells this starter shape for the least money. Its English VPS page, read on 11 November 2026, prices **Cloud VPS 4 at €4.40 per month excluding VAT**, and **€5.50** once that page view’s 25% tax is added, as the effective monthly rate **for the first 24 months** ([Contabo VPS](https://contabo.com/en/vps/)). That 25% is the tax added in the fetched page view. The page does not label it as German VAT. The machine is **4 vCPU, 8 GB RAM, 100 GB SSD, a 200 Mbit/s port, and unlimited traffic**. Dedicated IPv4 and IPv6 come with every plan, so there is no separate IPv4 line. One snapshot is included. Auto Backup is a paid add-on whose price is not on the page. The server is KVM, with full root and a customer-chosen Linux image, which is the access required to install Docker and hand the supervisor the socket. Incoming traffic is unmetered. Outgoing traffic is unlimited under a fair-use rule that lets Contabo throttle a server with exceptionally high or disruptive usage. That **200 Mbit/s** cap is the lowest stated port speed in the five, and it is the limit that matters if coturn is carrying media. A one-time setup fee applies to new Cloud VPS 4 orders on monthly contracts only, and the page does not print the amount. Longer contracts have no setup fee. The minimum first term is one month, and the following term matches it. The price after the first 24 months is not on the page. **€4.40 is the 24-month rate.** A one-month contract is a different, unpublished price plus that unstated setup fee.

Netcup, Hetzner, Contabo, and Hostinger withhold nested virtualization on these VPS plans ([Netcup server FAQ](https://www.netcup.com/en/helpcenter/documentation/server/faq); [Hetzner cloud server FAQ](https://docs.hetzner.com/cloud/servers/faq/); [Contabo nested virtualization](https://help.contabo.com/en/support/solutions/articles/103000271595-can-i-setup-nested-virtualization-on-my-server-); [Hostinger nested virtualization](https://www.hostinger.com/support/10429687-is-nested-virtualization-supported-in-hostinger/)). Netcup says the SVM flag stays off and tells customers to run Docker or Podman. Hetzner’s cloud FAQ gives the same answer for a hypervisor inside a cloud server. The supervisor starts containers on the host Docker daemon, which is the path those pages leave open.

## CPX32 is the Hetzner starter, and CPX42 is the next size

Staying on Hetzner means paying the regular-performance line. The orderable 4 vCPU / 8 GB plan on 11 November 2026 is **CPX32: 4 AMD vCPU, 8 GB RAM, 160 GB NVMe, at least 20 TB**, at **€30.49 per month in Helsinki and €35.99 in Nuremberg**, excluding VAT, with the page’s price label including one primary IPv4 ([Hetzner Regular Performance](https://www.hetzner.com/cloud/regular-performance/)). The row was available. Shared vCPU is what Hetzner describes as fit for low to medium CPU, and Docker is a free one-click image on cloud servers ([Hetzner Cloud](https://www.hetzner.com/cloud); [Docker CE](https://docs.hetzner.com/cloud/apps/list/docker-ce/)). Choosing IPv6 only saves **€0.50 per month excluding VAT** ([Hetzner European cloud](https://www.hetzner.com/european-cloud/)). Backups are a further **20% of the server price** for seven slots, so they sit outside the €30.49 ([Hetzner billing FAQ](https://docs.hetzner.com/cloud/billing/faq/)). A customer in Germany pays **19% VAT** on the net price. An EU customer outside Germany with a valid VAT ID pays the net figure under reverse charge ([Hetzner VAT](https://docs.hetzner.com/general/billing-and-account-management/billing-at-hetzner/value-added-tax/)). On those rules a German resident’s Helsinki CPX32 is **€30.49 × 1.19 = €36.28** before backups. CPX32 is about twice Netcup’s card and several times Contabo’s 24-month rate, and it is still about half of the machine in the current budget.

The same day’s US shared-cloud lists sit with CPX32, well above the five. ## Fly, Railway, and Render have no socket for the supervisor

Fly.io, Railway, and Render can host an API and a database, and the fetched docs give the supervisor nowhere to mount `/var/run/docker.sock`. A Fly Machine is one VM started from an image. The overview lists ephemeral storage, an optional volume, and a region, and it does not mention a host Docker socket, privileged mode, or a Docker daemon ([Fly Machines](https://fly.io/docs/machines/overview)). Railway’s public networking page describes HTTP and HTTPS, custom domains, and automatic SSL, and it does not mention a socket or UDP ([Railway public networking](https://docs.railway.com/reference/public-networking)). Render private services can speak almost any protocol and are unreachable from the public internet. Background workers can send requests and cannot receive them ([Render private services](https://render.com/docs/private-services)). Splitting the compose file into one service per process can cover an API, a worker, and Postgres. It leaves the supervisor unable to start `computer-headless` or `computer-desktop` on a shared daemon.

The rate cards are why the omission matters. On Fly’s Ashburn prices, a 512 MB machine is $3.69 per 30 days, a 1 GB machine is $6.70, and a 10 GB volume is $1.50, so an API, a worker, a 1 GB Postgres machine, and that volume add to **$15.58 per 30 days** before the gateway containers, Caddy, coturn, and the supervisor. Fly Managed Postgres Basic is **$38** before any app machines ([Fly.io pricing](https://docs.fly.io/about/pricing); [Fly Managed Postgres](https://docs.fly.io/postgres)). Railway Hobby is a **$5** subscription that includes $5 of usage, and at **$10 per GB-month** that $5 buys about half a gigabyte of RAM for the month and nothing else ([Railway pricing](https://docs.railway.com/pricing/plans)). The 11 November Render pricing extract lists the smallest paid web service at **$7**, a worker at **$7**, and the smallest paid Postgres at **$6**, and a 28 October 2026 Render article prices database disk at **$0.30 per GB**, which puts those three lines near **$20.30** with 1 GB of disk if that rate applies to the whole allocation. The pricing extract does not spell the disk out as included storage ([Render pricing](https://render.com/pricing); [Render compute plans](https://render.com/docs/compute-plans); [Managed PostgreSQL pricing in 2026](https://render.com/articles/managed-postgresql-pricing-2026)). The Fly and Render constructions land near Netcup’s card and still leave the bot computers unstarted. Coturn makes Fly a worse match on a second axis: public UDP requires a dedicated IPv4 at **$2 per month**, and the process must bind `fly-global-services`, while coturn is started with `--listening-ip=0.0.0.0`, the address Fly’s UDP doc calls the wrong source ([Fly UDP and TCP](https://docs.fly.io/networking/udp-and-tcp)). Free and trial modes are a separate trap. Render free web services sleep after 15 minutes without inbound HTTP, and free Postgres expires 30 days after creation ([Render free tier](https://render.com/docs/free)). Railway’s Serverless option sleeps a service after more than 10 minutes without outbound requests ([Railway vs Render](https://docs.railway.com/platform/compare-to-render)).

Supabase replaces Postgres and leaves the Docker host in place. Supabase Pro is **$25 per month** for one Micro project, and Micro is a shared CPU with **1 GB of RAM** and **60** direct connections ([Supabase pricing](https://supabase.com/pricing); [Supabase compute](https://supabase.com/docs/guides/platform/compute-and-disk)). A Helsinki CPX22, the 2 vCPU / 4 GB API box at **€16.99** including IPv4 and excluding VAT, plus that $25, is a second invoice beside a Docker host that still has only 4 GB. One Helsinki CPX32 at **€30.49** keeps Postgres on the same machine as the computers. Small compute is about $15 a month, so one project becomes **$25 + $15 − $10 = $30**. Medium compute is about $60, so the same sum is **$75**, already above the Helsinki CPX42 display price. The IPv4 add-on is another **$4**.

## Conclusion

The cut comes from stepping down to the size the project already documents, and then from refusing a teaser rate. A 4 vCPU / 8 GB host is the written fit for the API, Postgres, and one or two computers, so the standing CPX42 budget is paying for the following size. The invoices that stay cheap after the first term are OVHcloud’s no-commitment month, Netcup’s tax-inclusive term price, and RackNerd’s repeating annual rate. Contabo wins the opening two years and then publishes nothing. Hostinger’s promo expires into a figure that sits next to a Helsinki CPX32.

Port speed breaks the tie once coturn has to move media. The lowest euro price is also the only starter in the five with a stated **200 Mbit/s** cap. OVHcloud is the cheap European plan that states **1 Gbps** and already includes a daily backup, which is the pair the other low prices split apart. A restocked Hetzner CX33 would reopen “stay on the current provider” in that same band, and on this date the badge said the whole cost-optimized line was unavailable. Supabase and the three app platforms leave the same hole. The computers are sibling containers, and the docs fetched for those products show an API and a database with no host Docker socket.
