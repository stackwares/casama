Gallery

Themes, color schemes, wallpapers and skills for Casama, free and open source. See each one as it looks in the app, then open it in Casama.

Add your own look or skill

The gallery is a GitHub repository. Each item is a folder with a short item.json and its file. A pull request adds it, and once it is merged every Casama app sees it within half an hour, with no app update.

  1. Fork stackwares/casama-gallery.
  2. Add a folder under themes/, schemes/, wallpapers/ or skills/ with item.json and its theme.json, scheme.json, wallpaper.json or SKILL.md.
  3. Run node check.mjs. It checks the license, text contrast, fonts and file sizes, and updates index.json.
  4. Open a pull request. Casama reviews it; skills with scripts get a second review.

Looks use CC0 1.0 or CC BY 4.0, skills MIT or Apache 2.0. Photos from Unsplash's API can't be added here: use your own. In the app, Settings → Appearance → Share to gallery fills in an issue with your current look.

// themes/lagoon/item.json
{
  "name": "Lagoon",
  "author": { "name": "Casama",
              "url": "https://casama.ai" },
  "license": "CC0-1.0",
  "tags": ["teal", "calm"],
  "featured": true,
  "version": 1
}
