Gallery/Developers

Add to Casama

Made something for the gallery? Put the badge in your README, docs or site. It links to the item's page, which opens it in Casama or helps people get the app.

Every item has a page at https://gallery.casama.ai/i/<type>/<id>/, where the type is theme, scheme, wallpaper, skill, app, bot, routine, plugin or set, and the id is the item's folder name. Each page also has the ready-made snippet for that item under Add a badge to your README.

Markdown

[![Add to Casama](https://gallery.casama.ai/badge.svg)](https://gallery.casama.ai/i/skill/meeting-notes/)

HTML

<a href="https://gallery.casama.ai/i/skill/meeting-notes/"><img src="https://gallery.casama.ai/badge.svg" alt="Add to Casama" height="40"></a>

Replace skill/meeting-notes with your item. Links straight into the app use casama://app/gallery/<type>/<id>; on the web prefer the page, which works with or without the app.

Public data

The whole catalog is static JSON on this site, free to read from anywhere (CORS is open, no key). Casama servers read the same files. Each item keeps its own license, named in its record.

FileWhat's in it
/index.jsonThemes, color schemes, wallpapers and skills, with each look's full document so a preview can be drawn from the list alone.
/apps.json, /bots.json, /routines.json, /plugins.jsonApps (vendor MCP servers), starter bots, routine ideas and reviewed plugins, in the same record shape.
/sets.jsonStarter sets: a few items that work well together.
/authors.jsonAuthors by handle, with the items each one made.
/manifest.json, /manifest.sigSHA-256 of every file above, and its Ed25519 signature, so a copy can be checked.
/<type>s/<id>/An item's own files, as listed in its record's files (for example /skills/meeting-notes/SKILL.md).
/sitemap.xmlEvery item and author page.

A record carries id, type, name, author, license, tags, version, added and updated, and when they apply description, examples, access (what it can read and change, whether it runs code or needs a computer, how many credits it uses), needs, changelog and document. The catalog format is in the gallery's README.

Usage numbers

GET https://api.casama.ai/v1/gallery/stats needs no sign-in and is cached for ten minutes. It returns { "items": { "<type>/<id>": { "installers", "trending", "active", "success" } } }: people who added it, new this week, active in the last 14 days, and the share of runs that finish. Numbers are aggregate only. An item with fewer than 10 people has no numbers, and success needs at least 20 runs.
