## What you pay for

| Part | What it is | How it's billed |
|---|---|---|
| The software | The agent itself | Free if open source; a subscription if hosted |
| The model | Every step is a call to an AI model | Per use with your own key, inside a plan's credits, or free with a local model |
| The computer | Somewhere for the agent to work, often with a browser | Your own machine, or hours included in a hosted plan |

This page is about using an agent. Building a custom agent with a developer is a different budget,
priced as a project.

## Why the sticker price isn't the cost

Two plans at the same price can buy very different amounts of work. Before you compare, find out:

- **What a credit is.** On some products a credit's worth depends on how complex a task turns out
  to be, so you can't price a task in advance. On Casama Cloud a credit is a dollar.
- **How many computer hours you get.** Rakazo's entry plan has 25 a month. Casama's plans include
  5, 30, 100 or 300 hours.
- **What happens at the limit.** Does it stop, wait for next week, or start charging? Grok Bot
  moves to pay per use after its weekly pool.
- **Whether waiting costs money.** An agent waiting for your approval shouldn't be burning hours.
- **How many people.** Per-seat pricing adds up fast for a team.

## The cheapest way to run one

1. Install an open-source agent on a computer you already own.
2. Use a local model for routine work; nothing is billed.
3. Add your own API key for the hard tasks, and set a spending limit with the provider.

The catch is the time it takes to set up and look after, and a machine that has to stay on. See
[are there free AI agents](/learn/are-there-free-ai-agents).

## Questions

### What does an AI agent with its own cloud computer cost?

Hosted plans that include one start free with limited hours: Casama's Free plan includes 5 hours a
month and Manus gives 300 credits a day. Paid plans run from $15 to $200 a month. Self-hosted, the
computer runs on your own server.

### Is an AI agent cheaper than a virtual assistant?

It can be, for routine work done on a screen, but it needs checking and can't do everything a
person can. Price one specific job both ways, including the time you spend reviewing.

### How do I keep an AI agent from running up a bill?

Use a spending limit at every layer: a budget per agent if it has one, a cap with your model
provider, and a plan that stops at its limit instead of charging more.
