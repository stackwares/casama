## How they differ

MausBot is a local-first app that drives other agent tools such as Claude Code and Codex with your existing subscriptions. Casama runs its own agent on an isolated computer per bot, on your server or in the cloud, so bots keep working when your laptop is closed.

## Questions

### Is MausBot the same as OpenMausBot?

Yes. MausBot is the product and OpenMausBot is the repository's name.

### Is MausBot free?

The desktop app is free. MausBot Cloud costs $15, $49 or $99 a month, and model usage is never included.

### Can Casama reuse my Claude Code subscription?

No. Self-hosted Casama accepts API keys, local models and a ChatGPT plan.

### Which has more cloud computer hours?

MausBot's paid Cloud plans list more hours. Casama's plans include model credits and a free tier.
