## How they differ

The two projects start from opposite ends. OpenClaw is one powerful agent on your own computer that you reach from the chat apps you already use, and it trusts you to switch on the safety features you want. Casama is a team of bots, each on its own isolated Linux machine, with approvals on by default, native apps, workspaces for more than one person, and Casama Cloud if you'd rather not run a server.

## Choose Casama if

- You want each bot kept apart from your own files, on its own sandboxed computer, without setting that up.
- You want risky steps to wait for you from day one, with a checkpoint saved before destructive commands.
- More than one person will use it, with roles and separate workspaces.
- You'd like a hosted version, or to start hosted and move to your own server later.
- You want to watch a bot's screen live and take over.

## Moving from OpenClaw to Casama

Both use plain-language instructions, skills and schedules, so a setup carries over by hand: recreate each agent as a bot, paste its instructions, and re-add its schedules as routines. Chat apps reconnect per bot. Casama's gallery has ready-made skills and starter bots to fill gaps.

## Questions

### Is OpenClaw free?

Yes. OpenClaw's site says there is no subscription or paid edition. You pay your own model provider. Self-hosted Casama is also free.

### Is OpenClaw safe?

It can be set up safely, but its own docs say tools run on the host by default, with sandboxing and command approvals off until you turn them on. Casama starts with both on. See [is OpenClaw safe and free](/learn/is-openclaw-safe) for how to set it up more safely.

### Does Casama have as many chat apps?

No. OpenClaw lists about 29. Casama has ten, including Telegram, Slack, WhatsApp, iMessage, Teams and Discord.

### Can I use local models with both?

Yes. Both accept your own keys and local models. On Casama Cloud, Casama picks the model.
