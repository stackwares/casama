## Licences, in plain words

- **Rakazo**: Apache-2.0.
- **Casama**: AGPL-3.0 (SDKs and CLI Apache-2.0), with a separate `ee/` folder for a few enterprise features. It builds and
  runs without that folder.
- **MausBot**: Apache-2.0, with a source-available `enterprise/` folder.
- **OpenBot**: the app is MIT, but it needs CopilotKit Intelligence, which is licensed separately:
  free for personal use on a laptop, paid for production.

## Where each one runs a bot

- **Rakazo**: its own container per bot when self-hosted, or a cloud computer on hosted plans.
- **Casama**: its own sandboxed Linux machine per bot, self-hosted or on Casama Cloud.
- **OpenBot**: a container per person by default; a bot can be marked isolated to get its own.
- **MausBot**: your own machine by default; a cloud computer per bot on paid Cloud plans.

## Questions

### Are all four free to self-host?

Rakazo, MausBot's desktop app and Casama are. OpenBot is free for one person on their own laptop.

### Which has the most GitHub stars?

On the day we checked: MausBot about 24,700, OpenBot about 12,700, Rakazo about 9,000. Casama had
just been published.

### Do the hosted plans cost the same?

Rakazo, MausBot Cloud and Casama Cloud all use $15, $49 and $99 a month. What each includes
differs: computer hours, model usage, seats.
