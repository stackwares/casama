Switch on what a teammate needs.

Give every bot its own computer.

A sandboxed Linux desktop with a shell, files and a browser. Watch it live or take over the mouse. It sleeps after 5 idle minutes and wakes in seconds.

Ask me before anything risky.

Rules per bot and per action: allow, allow within limits, or ask first. A checkpoint is saved before each risky step, so Deny rolls the computer back.

Remember what I tell you.

Facts, preferences and past runs carry across every chat. Your About you profile stays out of team spaces unless you share it.

Keep working while I'm away.

Routines on a schedule, webhooks, email and calendar triggers, and watchers that spend nothing until a page changes.

Keep my keys away from the model.

Secrets live in an encrypted vault. The proxy adds them only for the right host, never to prompts, logs or run history.

First, you ask in plain words.

Type it, say it, or forward an email. Assign it on the ticket board if it can wait.

Safe enough to hand it real work.

Every boundary in Casama is enforced and tested, from database rows to container system calls and outbound traffic. Runs are durable: restart the server mid-task and they pick up from the last finished step.

Row-level security on every table
Each workspace table has a Postgres policy and a test proving one workspace can never read another.
Hardened computers
Bots run as non-root on a read-only system with dropped Linux capabilities, memory limits, and gVisor on Linux hosts.
Keys the model never sees
API keys and 1Password or Bitwarden items are added at the network edge, only for the hosts you allow.
Your data, portable
Optional encryption at rest, retention you set, and a full workspace export whenever you want it.
