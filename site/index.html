Get started Star on GitHub

Not a chat window. A colleague with a desk.

Remembers

Facts, preferences and past work carry across conversations. Skills and personas make each bot good at its job.

Works on a real computer

A sandboxed Linux machine with shell, files and a browser. Watch live and take control whenever you like.

Keeps going without you

Schedules and webhooks start work while you sleep. Results land in your inbox with what it did and what it cost.

Asks before it acts

Autonomy levels, approvals for risky steps, checkpoints before destructive commands, budgets per run and per day.

Any model

OpenRouter, OpenAI, Anthropic, Google, xAI, or a local model through Ollama. Fallbacks when a provider is down.

Everywhere you are

Apps for iPhone, Android, Mac, Windows, Linux and the web, a CLI, a Dart SDK, and an MCP server for coding tools.
